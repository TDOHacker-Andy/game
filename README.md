# Tactical Battle Sandbox v31 — 台日跨海戰役

現代虛構跨海戰區 RTS / tactical sandbox，採大型 2D SVG 地圖與 WebSocket authoritative server。

## Render
- Build: `npm install`
- Start: `npm start`

## 開局
- 開頭是房間大廳：可以「建立房間」（會顯示 4 碼房號，把房號傳給朋友即可跟你 PvP 對戰；不等朋友的話也能直接點「不等了，直接開打」單機打 AI），或直接「輸入房號」加入朋友的房間
- 朋友必須在房主按下「準備開始」之前加入

## 戰前
- 120 秒配置
- 軍費 30,000
- 6 種陸軍 + 3 種海軍
- 陸軍只能部署在己方本島；海軍只能部署在海上
- 雙方開局兵力**不對稱但總價值相近**：台灣（藍軍）陸軍偏重、海軍精簡；日本（紅軍）海軍偏重、陸軍精簡——玩法路線從一開始就不同

## 地圖
- 海岸線取材自真實世界公開地理資料（Natural Earth，CC0），分別簡化並依各自中心點放大約 2.3 倍：台灣本島＋九州，兩地相對方位、距離比例與現實一致，各城市設施位置也對應台北／台中／高雄／花蓮／基隆與熊本／福岡／長崎／鹿兒島／大分
- 中央海峽有一座中立中繼島（琉球意象），陸軍必須先搭乘運輸艦才能登陸——運輸艦一次只能搭載 1 隊陸軍，被擊沉搭載部隊全滅，制海權因此仍是決勝關鍵
- 南、北兩側另有狹長陸路走廊，實際與雙方本島接壤：陸軍下令跨海移動時，若附近有待命運輸艦會自動徵用走「快但需護航」的海路；沒有運輸艦則會自動走到岸邊等待運輸艦前來接應，長時間等不到才會改走「慢但不怕被擊沉」的陸路走廊。走廊中段各有一個易守難攻的隘口，隘口本身也是可佔領據點
- 森林、丘陵、山地均可通行但速度不同；山區可經隘口縮短路程

## 設施
- HQ／軍港／空軍基地／補給站／要塞：靠部隊在周邊駐留佔領，決定戰局主城
- 設施組成刻意不對稱：台灣多要塞／補給站／哨塔（陸軍國防），日本多軍港／空軍基地（海空優勢），但用總價值換算後兩邊大致平衡
- **工廠**：被動持續為擁有方累積軍費；一旦被打到摧毀就永久消失、不能被佔領轉移，是需要重兵守護、也值得偷襲的經濟目標
- **雷達站／哨塔**：佔領後大幅擴大己方偵知範圍，適合插旗在陸路走廊入口做早期預警

## 戰鬥
- 地圖為主要遊戲介面，不使用小地圖以外的資料表或戰鬥管理面板；右下角小地圖可點擊快速跳轉視角
- 觸控板：單指拖曳平移；點擊己方部隊選取；點擊空地移動；點擊已發現敵軍或敵方工廠攻擊
- Shift + 拖曳可框選
- `+ / -` 縮放，`R` 全圖
- AI 單人模式會組織艦隊護航跨海登陸，也會自行利用陸路走廊推進，不是原地待命的靶子；雙人 PvP
- 設施佔領進度、工廠軍費挹注、雙方傷亡數會即時顯示在地圖與 HUD 上
- 26 分鐘戰役；主城失守或一方全滅可結束

## 美術
- 地圖地形、走廊、設施圖示：前端程式原創向量即時繪製，不依賴外部圖片資源，縮放不失真、連線資料極輕
- 陸戰單位（突擊兵／偵察兵／特戰部隊／反裝甲／火力支援／裝甲部隊）與海軍單位（巡邏艇／護衛艦／運輸艦）改用真實圖片素材：陸戰單位取自 Kenney.nl「Top-down Shooter」「Top-Down Tanks」（CC0）；海軍艦艇取自 OpenGameArt「Sea Warfare Set」（CC0，作者 Lougi），並重新上色為雙方隊伍色。授權與來源詳見 `public/assets/units/CREDITS.txt`
