# Tactical Battle Sandbox v29 — 台日跨海戰役

現代虛構跨海戰區 RTS / tactical sandbox，採大型 2D SVG 地圖與 WebSocket authoritative server。

## Render
- Build: `npm install`
- Start: `npm start`

## 開局
- 開頭是房間大廳：可以「建立房間」（會顯示 4 碼房號，把房號傳給朋友即可跟你 PvP 對戰；不等朋友的話也能直接點「不等了，直接開打」單機打 AI），或直接「輸入房號」加入朋友的房間
- 朋友必須在房主按下「準備開始」之前加入

## 戰前
- 110 秒配置
- 軍費 20,000
- 6 種陸軍 + 3 種海軍
- 陸軍只能部署在己方本島；海軍只能部署在海上

## 地圖
- 台灣（藍軍）與日本（紅軍）分處海峽兩端，中間隔著大海與一座中立的中繼島
- 沒有陸橋──陸軍要跨海攻打對方本島，必須先搭乘運輸艦；下令跨海移動時會自動徵用附近待命的運輸艦
- 運輸艦一次只能搭載 1 隊陸軍；運輸艦被擊沉，搭載的部隊也會全滅──制海權因此決定登陸成敗
- 森林、丘陵、山地均可通行但速度不同；山區可經隘口縮短路程

## 戰鬥
- 地圖為主要遊戲介面，不使用小地圖以外的資料表或戰鬥管理面板；右下角小地圖可點擊快速跳轉視角
- 觸控板：單指拖曳平移；點擊己方部隊選取；點擊空地移動；點擊已發現敵軍攻擊
- Shift + 拖曳可框選
- `+ / -` 縮放，`R` 全圖
- AI 單人模式會組織艦隊護航跨海登陸，不是原地待命的靶子；雙人 PvP
- 設施佔領進度、雙方傷亡數會即時顯示在地圖與 HUD 上
- 23 分鐘戰役；主城失守或一方全滅可結束

## 技術
- 地圖與單位均由前端程式即時繪製，不依賴背景地圖圖片
- WebSocket 狀態在伺服器權威更新
