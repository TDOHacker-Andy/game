# Tactical Battle Sandbox v32 — 多情境戰場

現代虛構戰區 RTS / tactical sandbox，採大型 2D SVG 地圖與 WebSocket authoritative server，支援多種可自選的對戰情境。

## Render
- Build: `npm install`
- Start: `npm start`

## 開局
- 開頭是大廳：先選擇對戰情境（卡片點擊即建立房間），會顯示 4 碼房號，把房號傳給朋友即可跟你 PvP 對戰；不等朋友的話也能直接點「不等了，直接開打」單機打 AI；或直接「輸入房號」加入朋友的房間
- 朋友必須在房主按下「準備開始」之前加入；朋友加入的房間會自動套用房主選擇的情境

## 對戰情境
- **台灣 vs 日本（跨海峽）**：海岸線取材自真實世界公開地理資料（Natural Earth，CC0），台灣本島＋九州依真實相對方位、距離比例放大。中央海峽有一座中立中繼島，陸軍必須先搭乘運輸艦才能登陸；南、北兩側另有陸路走廊實際接壤兩地。雙方兵力不對稱但總價值相近：台灣陸軍偏重、日本海軍偏重
- **台北 vs 高雄（同島內戰）**：沿用台灣本島真實海岸線資料放大，沿南北向切成三段——北段（台北）／中段（中立緩衝區，五個據點串起的長戰線）／南段（高雄）。三段彼此直接接壤，純陸戰推進；外環仍保留真實海岸線，雙方可佈署海軍支援
- **亞洲大陸征服**：本階段重點新玩法。12 塊區域組成的大陸節點圖，雙方從對角兩端開局，中間大片區域無守軍、誰先佔領誰先得；佔領到的兵工廠直接挹注軍費、壯大軍隊；統一全圖或殲滅對方即獲勝。純陸戰，所有區塊以真實邊界相連，直接推進即可攻打鄰接領土
- 南韓 vs 北韓、中國 vs 美國等情境可用同一套 `scenarios/` 資料管線快速擴充

## 戰前
- 120 秒配置
- 軍費 30,000
- 6 種陸軍，情境有海軍時再加 3 種海軍（`hasNavy:false` 的情境如亞洲大陸征服，軍購介面會自動隱藏海軍選項）
- 陸軍只能部署在己方領土；海軍只能部署在海上

## 地圖與領土系統
- 所有情境共用同一套「領土節點」引擎：每個地塊都是一個 `landmass`（`home0`／`home1`＝雙方本土，`neutral`＝可通行的中立地塊，`isolated`＝需要運輸艦才能進出的孤立地塊），彼此以真實邊界相連或以走廊／運輸艦連接
- 雙方對決（`duel`）情境沿用「摧毀對方主城」勝利條件；大陸征服（`conquest`）情境額外支援「統一全圖（控制所有據點）」勝利條件，佔領到的兵工廠會直接歸屬佔領方持續產出軍費
- 陸軍跨海會自動徵用附近運輸艦（一次最多可搭載 3 隊陸軍，被擊沉時搭載部隊全滅）；若沒有運輸艦待命，會自動改走陸路走廊；純陸地的地形銜接（例如同一塊大陸的鄰接地塊）不會誤觸發運輸艦系統
- 森林、丘陵、山地均可通行但速度不同；山區可經隘口縮短路程

## 設施
- 所有據點（HQ／軍港／空軍基地／補給站／要塞／工廠／雷達站／哨塔）都有兩種攻佔方式：**駐留佔領**（部隊在周邊不受阻擋地駐留一段時間，佔領進度環會慢慢轉滿）或**砲擊攻陷**（集火打光它的血量，血量歸零時直接易主給打下它的一方、以半血重新啟用，不會永久消失）——防守嚴密的目標可以直接砲轟拿下，不需要先耗時間清空駐留
- **工廠**：被動持續為目前擁有方累積軍費，攻陷或佔領後由新擁有方接手收租
- **雷達站／哨塔**：佔領後大幅擴大己方偵知範圍，適合插旗在走廊入口或前線據點做早期預警

## 戰鬥
- 地圖為主要遊戲介面，不使用小地圖以外的資料表或戰鬥管理面板；右下角小地圖可點擊快速跳轉視角
- 觸控板：單指拖曳平移；點擊己方部隊選取（精準點在部隊圖示上一定會選取，即使目前已經選了別的部隊也一樣，方便切換陸海軍協同下令）；點擊空地移動；點擊已發現敵軍或敵方／中立據點攻擊
- Shift + 拖曳可框選；空白鍵可隨時取消目前選取
- `+ / -` 縮放，`R` 全圖（戰前建軍畫面也能用）
- 戰鬥中可隨時用兵工廠累積的軍費繼續建軍（軍購按鈕），也可隨時投降（需二次確認）
- AI 單人模式會依情境自動組織艦隊護航跨海登陸（僅限有海軍的情境）或直接陸路推進，不是原地待命的靶子；雙人 PvP
- 設施佔領進度、工廠軍費挹注、雙方傷亡數會即時顯示在地圖與 HUD 上；大陸征服情境的 HUD 會改顯示雙方領土控制數，取代單一戰線進度條

## 美術
- 地圖地形、走廊、設施圖示：前端程式原創向量即時繪製，不依賴外部圖片資源，縮放不失真、連線資料極輕；道路網路依各情境的設施座標自動生成
- 陸戰單位（突擊兵／偵察兵／特戰部隊／反裝甲／火力支援／裝甲部隊）與海軍單位（巡邏艇／護衛艦／運輸艦）改用真實圖片素材：陸戰單位取自 Kenney.nl「Top-down Shooter」「Top-Down Tanks」（CC0）；海軍艦艇取自 OpenGameArt「Sea Warfare Set」（CC0，作者 Lougi），並重新上色為雙方隊伍色。授權與來源詳見 `public/assets/units/CREDITS.txt`

## 技術
- WebSocket 狀態在伺服器權威更新
- `scenarios/` 資料夾存放每個情境的地理／設施／初始兵力資料（`tw-jp.js`／`tp-kh.js`／`asia-conquest.js`），伺服器在建立房間時載入對應情境；新增情境只需新增一個資料檔並在 `scenarios/index.js` 註冊，不需要更動引擎程式碼
